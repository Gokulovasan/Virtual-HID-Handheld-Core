# Virtual-HID-Handheld-Core
Virtual-HID-Handheld-Core is an industrial-grade, zero-hardware C99 input middleware layer designed to convert compact USB keyboards into virtual HID gamepads with mouse-pointer emulation. Developed specifically for low-power Linux single-board computers (such as Raspberry Pi) running emulation ecosystems (RetroArch, Batocera, Lakka)
